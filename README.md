Two systems show different sales totals for the same stores. Two simulated data sources: one uses actual transaction-level returns, the other uses a flat average deduction. The script joins them, calculates the variance for every store, flags anything outside 2% tolerance, diagnoses the root cause, and exports both an Excel report and a findings summary. 12 stores, 3,000 transactions, two root causes identified, run time <0.63 seconds. Automated and scalable using same problem-solving for real world.
