This script simulates the most common escalation — two systems showing different sales totals for the same stores. I built two synthetic data sources with a deliberate discrepancy: one uses actual transaction-level returns, the other uses a flat average deduction. The script joins them, calculates the variance for every store, flags anything outside 2% tolerance, diagnoses the root cause, and exports both an Excel report and a plain-English findings summary. 12 stores, 3,000 transactions, two root causes identified, done in under half a second. That's the diagnostic pattern I'd apply to any HelpDesk escalation in this role.
